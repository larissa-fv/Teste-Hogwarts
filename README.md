# Teste-Hogwarts

# O Portão de Hogwarts

Jogo para ensinar ACLs, firewalls e ZPF (Cisco NetAcad, Módulos 4, 5 e 6)
com analogias de Harry Potter. Cada aluno vira o Filch e decide quem passa
pelo portão, lendo uma lista de regras.

Para jogar: abra o link do GitHub Pages ou o arquivo index.html no navegador.
